# ERR India

**An ML-driven air quality intelligence platform for India.**

ERR aims to make air quality easier to understand through historical analysis, real-time monitoring and pollution forecasting.

The project is currently focused on building its data foundations: exploring historical air quality records, evaluating monitoring stations, studying data quality and developing reliable ingestion workflows.

## Repository

- `src/` — Data ingestion and analysis scripts.
- `docs/` — Research, technical documentation and observations.
- `data/` — Local datasets and processed data.
- `notebooks/` — Exploratory analysis and experiments.
- `requirements.txt` — Python dependencies.
- `.env.example` — Environment-variable template.

## Getting started

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Copy `.env.example` to `.env` and configure the required credentials.
5. Explore `docs/` and `src/` to get started.

ERR is actively evolving, with an emphasis on reliable data, careful research and meaningful forecasting.
